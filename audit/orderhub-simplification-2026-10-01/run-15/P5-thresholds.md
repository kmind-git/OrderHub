# P5 本地默认阈值留痕

确定时间：2026-10-02（Asia/Singapore）。沿用用户授权由实施方指定后续阈值。
本表适用于首期本地 USD 现金权益 profile，不构成部署容量或实盘额度承诺。
P4 新鲜度仍使用 [阈值 v2](../../orderhub-simplification-2026-09-29/run-05/thresholds-v2.md)。

| 项目                       | 默认值                           | 理由/达到上限后的行为                                                                   |
| -------------------------- | -------------------------------- | --------------------------------------------------------------------------------------- |
| 策略成本预算/策略市值敞口  | 各 USD 1,000,000                 | 分开计算成本与当前价格风险；规则版本 local-usd-v1。                                     |
| 账户现金预算               | 当前可信购买力与配置额度的较小值 | 不假定账户初始资金，不循环使用未确认卖出收入。                                          |
| 账户市值敞口               | USD 2,000,000                    | 同时计入外部总持仓及所有本地待成交占用。                                                |
| 单笔数量/名义金额          | 10,000 股 / USD 1,000,000        | 拒绝超单笔风险。                                                                        |
| 限价带                     | 当前参考卖价上下 10%             | 异常价格受理前持久拒绝。                                                                |
| 每单费用缓冲               | USD 1                            | 只用于本地零费模拟 profile；超过缓冲保存费用并 HALTED。真实通道启用前改用权威费用规则。 |
| 活动订单数                 | 每账户 4,096                     | 事务内拒绝超过可控查询数据集的订单。                                                    |
| 原生订单缓存               | 每进程 8,192                     | 达限 HALTED；P6 完成安全重建/归档后再扩展。                                             |
| 新单/撤单/查询队列         | 1,024 / 128 / 128                | 独立容量，洪峰不占用撤单队列。                                                          |
| 提交方在途新单             | 64                               | 队列/持久化期间持有名额，满时 RESOURCE_EXHAUSTED。                                      |
| 新单队列最长等待           | 250 ms                           | 超时前未开始受理，返回 DEADLINE_EXCEEDED。                                              |
| writer 队列/批量/回复等待  | 1,024 / 64 / 10 秒               | 满队列是明确未提交；回复超时视为提交未知并停单。                                        |
| FIX 帧/读回报/执行回报     | 16 KiB / 1,024 / 1,024           | FIX 读队列使用有界背压；执行队列满或读取断开关闭门禁，P6 对账补证。                     |
| RPC 解码/ID/十进制长度     | 16 KiB / 64 字节 / 40 字节       | 解析前拒绝超限，无指数/符号金额。                                                       |
| 凭证配置规模               | 128 凭证，每凭证最多 128 策略    | token 最多 256 字节；策略不可跨提交方重复分配。                                         |
| 快照活动订单/每页          | 4,096 / 1,000                    | 同一读事务，固定 N。                                                                    |
| 快照租约数量/逻辑字节/TTL  | 16 / 8 MiB / 60 秒               | 满额拒绝；过期回收；最后一页主动释放。                                                  |
| 订阅/每流缓冲/慢客户端等待 | 128 / 256 / 5 秒                 | 正常发送预留错误位置，超时显式 RESYNC_REQUIRED。                                        |
| stream token 有效期        | 1 小时                           | 过期重新取快照；绑定日志代、提交方和策略权限。                                          |
| 日志与事件视图逻辑字节     | 输入/新单 96 MiB；全部 128 MiB   | 留 32 MiB 给回报/撤单/状态；达限不删防重记录，HALTED 后交 P6 归档。                     |
| 日志记录数                 | 1,000,000                        | 序号达到上限停止写入。逻辑界限不等于 redb 物理文件字节界限。                            |
| 原生账户历史               | 最新状态                         | 历史在持久业务日志；禁止内存账户事件无限累积。                                          |

这些值没有通过扩大限额掩盖失败。A14 使用 64 个排队新单、128 个排队查询和独立撤单、
257 条待推事件、16 个租约及实际超时验证边界；不替代后续生产容量测试。
