## Required defect and acceptance split

These are source-observed defects or missing guarantees to reproduce in isolated tests. Existing
`m0_*`, `m1_*`, and `m2_*` tests are baseline prototypes, not A01-A16 remediation evidence.

| Area | Current source evidence | Required acceptance after repair |
| --- | --- | --- |
| Premature READY | `crates/orderhub-node/src/main.rs` scans the journal and sets READY before full state rebuild, input refresh, or exchange reconciliation. | A09: replay and unresolved-order fault tests deny new risk until all prerequisites hold. |
| Incomplete fill fact | `crates/orderhub-gateway/src/journal.rs` records only client order ID and filled quantity for fills. | A04/A06/A09: stable fill ID, price, fee, account, and ownership replay identically. |
| Query and stream authorization | `crates/orderhub-gateway/src/grpc.rs` authenticates GetState/WatchEvents without filtering per submitter; CancelOrder does not enforce owner at RPC entry. | A13: cross-submitter cancel/query/stream attempts are denied or filtered. |
| Lost persistence failure | `crates/orderhub-gateway/src/exec_wiring.rs` discards `submit_outcome` errors. | A10: write failure becomes observable and closes new-order admission. |
| Resource bounds | `crates/orderhub-node/src/main.rs` uses an unbounded execution-event queue; `scan_after` materializes all tail entries for a stream. | A14: bounded queues, paging, slow-consumer behavior, and reserved cancel capacity. |

## Stage gate

P0 has a reproducible baseline, asset ownership, data inventory, and versioned thresholds.
It has **not** established a running-node resource baseline or a complete unfiltered dependency
graph. P0 therefore remains open. Its build and test failures are recorded rather than called
passes. Static C0 inventory and other independent design work may continue, but the dependent P1
prototype gate is not complete and no C-dependent implementation should be removed on this
evidence alone. P8 remains blocked until every required acceptance row actually passes.
