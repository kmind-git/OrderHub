## 受理与执行

凭证配置经校验后重建 token 索引，服务端绑定提交方和当前策略权限。
RPC 检查日志代、字段长度和精确数值；摘要使用规范化的业务参数及业务截止时间。
同键同参数返回原结果，同键不同参数返回 `ALREADY_EXISTS`。
格式错误在入队前拒绝；能力、输入或风险规则拒绝保存为原 `REJECTED` 结果。

redb 的同一事务写入请求键、原结果、订单、账户/策略占用、
待发送状态、日志及该条事件的不可变投影。提交成功前不 ACK、不调用原生执行链。
async 使用 None 提交并后台统一刷盘；sync 使用 Immediate 并等待持久提交。
成功受理仍经过 Cache → 原生 RiskEngine → ExecutionEngine，未开启风控 bypass。
`DISPATCH_STARTED` 先提交到账本，async 不等其刷盘；随后在进入原生链和实际 FIX 写入前复核动态输入/截止时间。
提交/工作线程回复未知时关闭新单门禁，保留占用和原 ID。
发送前复核账户/状态时效、合约、截止时间和生命周期，不复核报价年龄/连续性。
旧 `PRICE_BAND` 拒绝请求同键重试仍返回原结果，不因规则修订重新判断。

执行回报先按所选模式提交完整身份、稳定成交 ID、精确价格/数量/费用、币种和时间，
再交给原生执行引擎。原生发布时再次观察同一事实不会重复结转。
同成交身份经济内容冲突、归属错误或不支持的成交修正关闭门禁，等待对账。
部分成交、终态后的迟到成交和费用同事务更新经济账本；全量成交优先于迟到撤销。
费用超过原缓冲先保存事实，再 HALTED。执行记录写失败不发布该事实、不释放占用。

## 成本与额度

账户输入的 `ownership[].cost_basis` 是已确认的 USD 持仓成本金额，不是单位均价。
正持仓缺少成本时关闭新风险门禁，禁止用当前行情猜测成本。
初始确认数量/成本进入持久策略账本；之后外部快照不覆盖已提交成交账本，
数量减少按更保守的可用值限制卖出，差异由 P6 对账处理。

策略成本预算与当前市值敞口分别计算；买单加剩余限价金额和费用预留，
卖单扣减已确认的可用归属数量。账户与策略同时约束，避免多个策略重复使用现金或持仓。
部分卖出释放的成本向零舍入到 USD 分，剩余成本保留；卖完时精确释放剩余成本。
销售收入尚未取得结算/对账依据时不再循环用于新买单。
撤单请求保留发送中订单占用；未越过发送边界的订单可同事务本地取消并释放。
成交后的剩余费用缓冲保留到迟到费用或后续对账确认。

## 查询与补流

GetState 的 Snapshot/OrderLookup/RequestLookup 读取已提交账本。
快照和 WatchEvents 不包含报价行情；重启后由行情源重新提供报价。
async 的查询和事件可以超过已刷盘水位；GetState 另行返回 persistence_mode 和 durable_cursor。
快照在一个读事务固定版本 N，分页租约保存该数据集；终态订单和原请求结果可独立查询。
WatchEvents 从签名 token 的 N 连续扫描有界持久页，不通过内存广播切换而漏事件。
每个业务事件附带当次提交的订单、持仓及策略资金视图，不能用最新状态替代历史版本。
事件 ID 为 `epoch:seq`，原生成交身份另行保留。64 位序号/时间及经济数值以字符串展示。

凭证、日志代和策略权限绑定到 token。旧代、过期 token、权限变化和签名篡改均拒绝。
账户视图只表示授权策略的账本占用/已用现金；不授予账户全局余额权限。
流中的账户输入只返回筛选后的策略归属，不返回总资金、购买力或其他策略。
业务与连接状态变化持久记录；实时 `writable/stale` 独立报告交易可写性及必需输入故障，
不保证报价实时，也不推进快照游标。
写入/执行 HALTED 时事件流显式返回不可用；慢消费者收到重同步原因后重新取快照。

## 资源与保留

具体值及选择理由见 [P5 阈值](../../audit/orderhub-simplification-2026-10-01/run-15/P5-thresholds.md)。
新单、撤单、查询有独立有界接入队列；每提交方限制在途新单。
活动订单、原生订单缓存、分页数据集、租约、订阅、输入/FIX/执行回报均有上限。
原生账户事件只保留最新状态，非报价输入历史保留在业务库。

本期不按年龄删除日志/防重索引。持久记录及不可变事件视图合计设逻辑字节上限，
接近上限停止新单/输入，给撤单、回报及停机状态留下预留。
达到最终上限时停止写入并保持 HALTED，交由 P6 的检查点/归档机制处理。
这是逻辑 payload 上限，redb 文件还包含表、索引及页面开销，不等同于物理文件大小承诺。
