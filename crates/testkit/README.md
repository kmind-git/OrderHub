# nautilus-testkit

Minimal local test support for OrderHub.

- `cache` (default): In-memory Cache database double.
- `high-precision`: Uses the retained model 128-bit fixed-point types.
- Event collection and correlation helpers are always available.

Dataset downloading, generic actor/strategy fixtures, and ITCH utilities are retired.
Tests consume checked-in fixtures without network preparation.
